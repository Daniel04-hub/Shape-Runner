# Shape Runner

A classic 2D top-down arcade game built with Python. Collect all the coins, avoid the bouncing enemies, and progress through increasingly difficult levels!

## Features
- **Core Gameplay**: Move your player to collect yellow coins while avoiding red enemies.
- **Level System**: Clearing the map increases difficulty with more walls and enemies.
- **Web Build**: Includes a Playable Web Version (WASM).
- **Audio**: Sound effects for collecting coins, collisions, and game over.

## How to Run Locally
1. Install dependencies:
   ```bash
   pip install arcade
   ```
2. Run the game:
   ```bash
   python main.py
   ```

## Web Version
Navigate to the `web_build` folder to see the source code for the web version (Ported to Pygame for WASM compatibility).
